# webtools

Personal Python utilities for working with web content.

## Install (local)

pip install -e .

## Install (from Git)

pip install git+https://github.com/YOUR_USERNAME/webtools.git

## Usage

```python
from webtools import fetch_web_text

text = fetch_web_text("https://example.com")
print(text)
```
